# Школьный компоновщик расписания

Автономное приложение для составления школьного расписания: база классов, педагогов,
кабинетов и предметов, автоматическая генерация уроков и подстановка замен.
Полностью на русском языке, работает в любом браузере.

## Способы запуска

### 1. Локально без базы данных (проще всего)

Данные хранятся в одном JSON-файле `./data/app-state.json`. PostgreSQL не нужен.

```bash
npm install
npm run build
npm start
# открыть http://localhost:3000
```

При первом запуске загрузится демо-школа и автоматически составится расписание.
База и расписание экспортируются/импортируются одним JSON-файлом через меню
«Данные и версии» (Ctrl+E — быстрый экспорт).

### 2. Локально с PostgreSQL

```bash
export DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/app_db
npx drizzle-kit push   # создать таблицы
npm install
npm run build
npm start
```

`src/db/schema.ts` содержит все таблицы; `npx drizzle-kit push` применяет их.

### 3. Docker (одной командой, где угодно)

```bash
docker compose up --build
# приложение на http://localhost:3000, данные в ./data/app-state.json
```

Чтобы включить PostgreSQL — раскомментируйте сервис `db` в `docker-compose.yml` и
задайте `DATABASE_URL=postgresql://postgres:postgres@db:5432/app_db`.

## Переменные окружения

| Переменная        | Назначение                                                        |
| ----------------- | ----------------------------------------------------------------- |
| `DATABASE_URL`    | Если задана — используется PostgreSQL. Если пуста — локальный JSON. |
| `JSON_DB_PATH`    | Каталог для файла состояния в режиме без БД (по умолчанию `./data`). |

## Структура

- `src/lib/store.tsx` — состояние, автосохранение, undo/redo, экспорт/импорт JSON.
- `src/lib/generator.ts` + `src/lib/engine.ts` — движок автоподбора расписания.
- `src/lib/validate.ts` — проверка данных и готового расписания.
- `src/lib/substitutions.ts` — подбор замен педагогов.
- `src/views/*` — экраны: обзор, сетка, генерация, замены, справочники.
- `src/lib/persistence.ts` — слой хранения (Postgres или локальный файл).

## Правила генерации (основные)

- Специализированные кабинеты в приоритете; стандартный — только если профильный занят.
- Часы по учебному плану совпадают с заданной нагрузкой.
- У класса — без окон в течение дня (строго).
- У педагога — не более 2 окон подряд (строго, межсменный перерыв не считается).
- Смены не пересекаются по времени; при перекрытии предлагается сдвинуть вторую.
- Приоритет против двух уроков подряд у одного педагога по одному предмету.
